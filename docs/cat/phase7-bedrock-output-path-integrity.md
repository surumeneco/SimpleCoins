# Phase 7: Bedrock pack and mapping output path integrity (CAT Draft)

Status: **Draft**, not Confirmed. Parent: TASK-20261031-SIMPLECOINS-100; leaf: TASK-20261101-006.

## Process / PI

`BedrockPack.write` creates a Bedrock resource-pack archive and a matching Geyser mapping JSON in operator-controlled plugin directories. The pack and mapping output paths, including existing ancestor directories, must not redirect through symbolic links. Reject unsafe paths before creating temporary files, and revalidate before atomic replacement. No generated bytes may be written to a symlink target outside the intended plugin directory.

This is a best-effort local filesystem guard, not an atomic two-artifact publication transaction. A future coherent JE/BE release must still verify both outputs and Geyser runtime registration.

## TCE / acceptance vectors

- SC-BEDROCK-PATH-01 (Red): a symlinked parent for the pack output is rejected without writing an archive into its target.
- SC-BEDROCK-PATH-02 (Red): a symlinked parent for the mapping output is rejected without publishing either output.
- SC-BEDROCK-PATH-03 (Red): a symlinked destination file is not followed or overwritten.
- SC-BEDROCK-PATH-04 (Regression): normal real output directories produce a valid pack and mapping through atomic replacement.

## Gate and live integration

CAT Draft only. Formal machine gates, live Geyser pack loading and JE/BE client distribution **not-run**.
